# Frutería Super SEGA

Leer README.md y docs/AVANCE.md antes de trabajar. Respetar el trabajo por etapas: no implementar etapas adicionales sin solicitud del usuario. Este proyecto es independiente de SINAÍ/catalogodeproductos.

Usar Node.js/Express y MySQL para el proyecto final. La etapa 1 es una demostración pública con datos ficticios, sin autenticación y sin base conectada. No confundirla con administración real. Nunca copiar credenciales, tablas o configuración de despliegue del proyecto anterior.

Colores acordados: verde, rojo y morado. Alcance: catálogo, menudeo, categorías, ofertas, disponibilidad y contacto WhatsApp. Sin pedidos, carrito, pagos, IA o sincronización SICAR.

Ejecutar npm run check y npm test ante cambios de código. Al terminar la etapa, actualizar docs/AVANCE.md con pruebas, enlaces y pendientes.
